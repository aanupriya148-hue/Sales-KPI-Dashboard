# Sales-KPI-Dashboard
Interactive Sales KPI Dashboard created using Excel/Power BI to analyze sales performance, revenue, profit and key business metrics.
📊 Sales KPI Dashboard

📌 Project Overview

The Sales KPI Dashboard is an interactive data analytics project designed to analyze and monitor sales performance using key business metrics. The dashboard provides a clear view of sales, revenue, profit, quantity sold, and other important performance indicators.

🎯 Objectives

- Analyze overall sales performance.
- Track important Key Performance Indicators (KPIs).
- Identify top-performing products and categories.
- Compare sales and profit across different regions.
- Understand sales trends over time.
- Support data-driven business decisions.

🛠️ Tools & Technologies

- Microsoft Excel
- Power BI
- Data Cleaning
- Data Analysis
- Data Visualization
- Pivot Tables
- Charts & Graphs
- DAX (if Power BI was used)

📈 Key KPIs

The dashboard includes important metrics such as:

- Total Sales
- Total Profit
- Total Quantity Sold
- Number of Orders
- Average Sales
- Profit Margin
- Sales by Category
- Sales by Region
- Monthly/Yearly Sales Trends

📊 Dashboard Features

- Interactive KPI cards
- Sales trend analysis
- Category-wise sales analysis
- Region-wise performance
- Product performance analysis
- Profit analysis
- Interactive charts and graphs
- Easy-to-understand visualizations

🔄 Project Workflow

1. Collected the sales dataset.
2. Cleaned and prepared the data.
3. Performed data analysis.
4. Created calculated fields and KPIs.
5. Designed interactive charts and visualizations.
6. Built the final Sales KPI Dashboard.
7. Analyzed the results and identified important business insights.

💡 Key Insights

The dashboard helps identify:

- High-performing products and categories.
- Regions generating higher sales.
- Monthly sales trends.
- Profitability patterns.
- Areas that require improvement.
- Overall business sales performance.
